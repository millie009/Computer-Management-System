# Computer Management System

## Project Overview
The Computer Management System is a desktop application developed to help users manage computer equipment, software, maintenance activities, and reports.

## Objectives
- Manage computer inventory.
- Keep records of installed software.
- Track computer maintenance activities.
- Generate and view reports.
- Provide a simple dashboard for easy navigation.

## Features
1. Dashboard
2. Computer Inventory
3. Software Inventory
4. Maintenance Management
5. Reports
6. Settings

## Technologies Used
- HTML
- CSS
- JavaScript
- Electron
- Node.js

## Installation
The application is packaged for Windows using Electron Builder.
